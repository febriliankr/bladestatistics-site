你的电脑，你的文件

Blade 用你电脑上已有的 R 和 Python，在你选的文件夹里工作。数据文件从不上传。每次写文件和每条命令都等你批准。

托管 API 负责规划并保管模型密钥。它保存会话记录，不保存你工作目录里的任何内容。

我需要会 R 吗？

不需要。你用平常的话提问，读解释就行。R 是留给别人要看你过程的时候。它自己会跑。

能打开我的 SPSS 文件吗？

能。SPSS 的 .sav 通过 R 读取，CSV、TSV、Excel 和 Parquet 也一样。变量标签和值标签都保留。

统计能交给语言模型吗？

算数不能，所以它从不算数。模型选过程、读输出，计算由 R 完成。选择和语法你都看得到。

我的数据会离开电脑吗？

你的文件留在你的文件夹里。托管 API 负责规划分析并保存会话记录。它从不接收你的数据集。每次写入和命令都会先问。

这能替代统计师吗？

它替代的是花在菜单、语法和排版上的时间。它不判断你的设计能否支撑结论。数据答不了的问题，它会直说。
